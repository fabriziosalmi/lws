Linux Web Services Unified CLI for Proxmox + LXC + Docker

Manage Proxmox hosts, LXC containers, and Docker applications running inside them, from one CLI, over SSH or a REST API.

Get Started Documentation 
# Install and run your first container
git clone https://github.com/fabriziosalmi/lws.git
cd lws && pip install -r requirements.txt
lws lxc run --image-id ubuntu-22.04 --size medium --count 3

Workflow

Proxmox host, to LXC container, to a Docker application inside it

1. Proxmox

List and inspect Proxmox hosts

lws px list
→

2. LXC

Create a container

lws lxc run --size medium
→

3. Docker

Deploy a Compose application into it

lws app deploy install

Example: create a container and deploy a Compose application

# 1. Create an LXC container (prints the assigned instance ID)
lws lxc run --image-id ubuntu-22.04 --size lws-web --hostname web-1

# 2. Install Docker in it (replace 100 with the ID from step 1)
lws app setup 100

# 3. Deploy an existing docker-compose.yml into it
lws app deploy install 100 --compose-file ./docker-compose.yml

Features

Retries and Timeouts

SSH command execution with automatic retry and timeout handling

Security Groups and Firewall Rules

Manage Proxmox firewall security groups and per-container rules from the CLI

Multiple Hosts

Target containers across multiple Proxmox hosts, grouped into regions and availability zones in config.yaml

Resource Monitoring

CPU, memory, and disk monitoring, and scaling recommendations via lxc scale-check

Docker Integration

Install and manage Docker containers within LXC containers

Scaling Commands

lxc scale-check recommends CPU/memory/storage changes against configured thresholds; lxc scale applies them - both run on demand, not as a background process

Backup and Restore

Snapshot management and container backup/restore

REST API

A REST API covering most CLI commands, with Swagger documentation and a Web UI
